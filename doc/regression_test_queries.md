# 회귀 테스트 문장

`tests/conftest.py` 에 같은 문장이 상수로 있고, 문장마다 막아야 할 알레르기 정답(`QUERY_FORBIDDEN`)을 손으로 적어 두었다. 모든 응답에 `assert_safe` 를 건다.

| 문장 | 확인하는 것 |
|---|---|
| 어제 술 먹고 치킨까지 먹어서 속이 안 좋아. 기름진 건 못 먹겠고 혼자 먹을 건데 만원 안쪽으로 20분 안에 되는 거 없을까 | 노트북 case1. 예산 10000·시간 20 추출, 속편한 메뉴 우선 |
| 오늘도 속이 별로야. 어제처럼 만원 안쪽으로 20분 안에 먹을 수 있는 걸로 추천해 줘 | 노트북 case1b. 같은 사용자 재방문 때 직전 추천·먹은 메뉴 제외(서버 재시작 후에도) |
| 친구 세 명이랑 저녁 먹는데 매운 게 당겨. 예산은 1인 15000원까지 괜찮고 시간은 넉넉해. 새우 알레르기 있는 친구가 있어 | 노트북 case2. 1인 예산, 새우 차단, 매운 메뉴 우선 |
| 돈이 없어서 5000원 안쪽으로 먹어야 해. 근데 밀가루 알레르기 있어서 면이랑 빵은 못 먹어 | 노트북 case3. 후보 0 → 예산 5000→8500 승인 요청, 승인·거절 두 경로 |
| 해산물 알레르기 있어. 저녁 추천해 줘 | 해산물 → 새우·오징어·조개·생선. 북엇국(북어)도 빠져야 한다 |
| 해산물 알레르기가 있어서 점심은 해산물 없는 걸로 추천해 줘 | 같은 내용, 다른 표현 |
| 점심 추천해 줘. 밀가루 알레르기 있어 | 표기 정규화(밀가루 → 밀), 점심에 간식 메뉴 제외 |
| 고수 알레르기 있어. 점심 추천해 줘 | 메뉴 데이터에 없는 재료. 막을 것이 없으니 정상 추천 |
| 점심 추천해 줘. 밀이랑 대두랑 계란이랑 돼지고기랑 소고기랑 생선이랑 유제품이랑 새우랑 땅콩이랑 닭고기랑 메밀이랑 조개 알레르기 있어 | 모든 메뉴 차단. 풀 조건이 없으니 묻지 않고 no_result |
| 안녕하세요. 어떤 일을 할 수 있나요? | route=chat |
| 제 이름은 민수입니다 → 제 이름이 뭐였죠? | 대화 기록으로 이름 기억 |
